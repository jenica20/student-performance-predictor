# student-performance-predictor
Machine Learning model to predict student pass/fail.
🎓 Student Performance Predictor (Machine Learning Project)

This is a beginner-friendly Machine Learning project that predicts whether a student will Pass or Fail based on four features:

Hours Studied

Attendance

Sleep Hours

Assignment Completion

This model uses Logistic Regression and StandardScaler to improve accuracy.
It also includes accuracy evaluation and a graph visualization.

📌 Features

✔ Predict student performance (Pass/Fail)
✔ Uses Logistic Regression
✔ Uses Standard Scaler for better accuracy
✔ Accuracy score displayed
✔ Confusion Matrix & Classification Report
✔ Custom input prediction
✔ Scatter plot visualization

📂 Dataset

The dataset is manually created with 20 sample student records.

Features:

Feature	Description
Hours	Study hours
Attendance	Attendance %
Sleep	Sleep hours
Assignments	Assignment completion %
Result	0 = Fail, 1 = Pass
🧠 Machine Learning Steps

Import libraries

Create dataset

Scale features

Split into training & test sets

Train Logistic Regression model

Test model accuracy

Predict new student's result

Plot graph

🧪 How to Run the Project

Make sure you have Python installed.
Then install the required libraries:

pip install pandas scikit-learn matplotlib


Run the Python file:

python student_model.py

Model Accuracy
